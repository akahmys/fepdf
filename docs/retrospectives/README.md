# Retrospectives

What happened, as it was understood at the time.

**Never updated.** These keep the names, figures and conclusions that were true when
written, including the project's former name — they were deliberately excluded from
the `ferruginous`→`fepdf` rename. Editing them would destroy the record they exist to
be.

For decisions and their reasoning, see [`docs/adr/`](../adr/README.md), which is
maintained and cross-referenced. A retrospective describes a period; an ADR describes
a decision.
